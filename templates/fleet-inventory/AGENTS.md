# AGENTS.md — private fleet inventory

This repository holds **real** hosts, deployment targets, and encrypted secrets.
Shared modules and the `fleet` CLI come from public **fleet-kit** (flake input **`fleetkit`**).

## Hard rules

1. Never commit plaintext secrets or age private keys.
2. Do not copy public modules into this repo; import `inputs.fleetkit.*`.
3. After kit CLI/module changes: `nix flake update fleetkit`.
4. Keep sanitized templates in kit free of real IPs/hostnames when syncing structure back.

## Task → skill routing

Skills are English playbooks. Prefer symlinks into kit (recreate with `just skills-link`):

| Intent | Skill |
|---|---|
| Add host | `skills/add-host` → kit `skills/add-host` |
| Deploy/sync/lock debug | `skills/debug-deploy` → kit `skills/debug-deploy` |

Claude Code: `.claude/skills` → `./skills`.

Human docs (in kit): `../fleet-kit/docs/` (setup-host, troubleshooting, infect, image).

## Common commands

```shell
just inventory-list
just inventory-add-host <name> --target-host <ip>
just inventory-doctor
just doctor
just sync --dry-run --builder default
just deploy <host> --builder default
just secrets-audit
just eval
```

## Layout

```text
hosts/          # per-host nix + hosts/default.nix index
secrets/        # sops-encrypted yaml (git-tracked ciphertext)
fleet.toml      # builder + repos.inventory_name / public_name
vars/           # identity for this fleet
Justfile        # regenerated by `just up` (does not touch Justfile.local)
Justfile.local  # private-only recipes (optional)
skills/         # symlinks to fleet-kit/skills/*
.claude/skills  # symlink to ./skills
```
